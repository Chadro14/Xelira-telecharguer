Politique d'utilisation

Xelira Download est une interface utilisant un service API tiers. L'utilisateur est responsable du contenu qu'il télécharge et doit respecter les droits d'auteur, les conditions d'utilisation de TikTok et les lois applicables. Xelira ne revendique aucun droit sur les contenus téléchargés.

Les résultats dépendent du service API tiers et peuvent changer ou devenir indisponibles sans préavis.
